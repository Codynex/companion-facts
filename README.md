# companion-facts

Daily Bible fact cards (English and Tamil) for my personal study companion app.

- `facts.json` — the feed the app downloads. New cards are added every day.
- `built_in_ids.txt` — ids of the cards built into the app (a feed entry with the same id replaces one).
- `scripts/validate.py` — checks the feed before each update.

**Found a mistake?** Tap the flag on the card in the app, or open an issue titled `Fix: <card id>`.
The next daily update fixes or removes it.

Every card is researched from wol.jw.org / jw.org, retold in my own words with a scripture reference, and links to the page it came from (the app's "Learn more" button opens it).
